# 토모에 보이스 정책 (2026-09-01)

- 정본 번역 모델: **Codex internal** (`gpt-5.5`, current root task)
- 토모에는 원문의 간사이 방언 기능을 한국어의 부드러운 경상권 말투로 보존한다.
- 대표형: `내/내는`, `그라모/그라네예`, `우째`, `참말로`, `~예`, `~데이`, `~지예`, `~하이소`, `~입시더`.
- 젊고 부드러운 인상을 유지하며 모든 문장 끝을 기계적으로 사투리화하지 않는다. 원문이 중립적인 순간에는 중립 문장도 허용한다.
- 주인공을 부르는 `センセ`는 토모에 대사에서 **쌤**으로 통일한다. 다른 인물의 `先生`은 이 규칙으로 바꾸지 않는다.
- 전투·필드·오더 진행 대사·벌주기 대사에도 같은 정책을 적용한다. 오더 제목처럼 발화가 아닌 UI 등록명은 표준어를 유지한다.
- 다른 학생의 비표준 말버릇, 자기 이름 1인칭, 거친 말투, 말줄임, 존댓말은 표준어로 평탄화하지 않는다.
