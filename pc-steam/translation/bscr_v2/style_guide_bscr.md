# Criminal Girls Invite Only — BSCR 한국어 번역 스타일 가이드

## 1. 번역 기준과 적용 범위

- **의미 원문은 일본어판 BSCR**이다. 영어판 BSCR은 정렬 가능한 경우 문맥·고유명사·생략 보조 자료로만 사용한다.
- 일본어와 영어가 충돌하면 일본어의 의미, 인물 관계, 높임말, 감정 강도, 성적 표현을 우선한다. 영어판 표현을 역번역하거나 영어판의 검열·의역을 따라가지 않는다.
- 같은 일본어 문자열이라도 화자·장면·선택지 역할이 다르면 문맥별로 번역한다. 단순 전역 치환은 금지한다.
- `present_unchanged_in_english` 또는 JP/EN 문자열 동일 여부는 내부 키라는 증거가 아니다. 실제 BSCR 소비자가 표시 함수인지로 가시성을 판정한다.
- 성적 표현과 `おしおき` 장면은 원문의 수위와 뉘앙스를 그대로 옮긴다. 검열, 완곡화, 임의의 선정성 추가를 하지 않는다.
- 초벌 번역을 전부 만든 뒤, 별도의 통합 검수에서 문체·용어·문맥·잔여 일본어를 한 번에 교정한다.

## 4. 화자별 문체

### 주인공 / 내레이션

- 남성 1인칭. 담담하고 자연스러운 해라체를 기본으로 한다.
- 속마음은 문어적으로 굳히지 말고 실제 독백처럼 쓴다.
- 선택지는 짧고 즉각적으로 읽히게 하며 마침표를 붙이지 않는다.

### 미우

- 냉정하고 단정한 명령조를 쓰는 성인 관리관이다.
- 초반에는 거리감과 통제력을 유지하고, 후반에는 갑자기 다른 인물처럼 바꾸지 말고 부드러움을 점진적으로 늘린다.
- `キミ`→`너`, `$0くん`→`$0 군`을 고정한다.

### 키사라기

- 돈과 체면을 중시하는 새침하고 공격적인 10대 말투다.
- 초반의 허세와 방어적 공격성, 후반의 솔직함이 대비되어야 한다.
- 본명은 반드시 **키사라기 쿄카**이며 영어판식 `Kyoko`는 금지한다.

### 란

- 거친 불량아의 짧은 반말과 욕설을 유지한다.
- 문장을 지나치게 예쁘게 다듬거나 욕설을 순화하지 않는다.
- `オヤジ`는 **아저씨**로 고정한다.

### 앨리스

- 말수가 적고 문장이 자주 끊긴다. 긴 말줄임표와 침묵의 간격을 보존한다.
- 어린 자기호칭과 불완전한 표현을 성숙한 문장으로 고치지 않는다.

### 토모에

- 부드러운 간사이 사투리의 친근함을 살리되, 한국어에서는 완만한 동남 방언을 소량만 쓴다.
- 모든 어미를 과장된 사투리로 바꾸거나 희화화하지 않는다.
- `センセ`는 **선생님**으로 고정한다.

### 사코

- 히라가나 중심 원문의 유아적이고 기운찬 짧은 반말을 살린다.
- 문법적 매끈함보다 아이 같은 직진성과 반복을 우선한다.
- 성인식 어휘나 설명조로 다듬지 않는다.

### 유코

- 밝고 상냥하며 비교적 예의 바른 동생 말투다.
- 사코보다 문장이 정돈되어야 하지만 지나치게 격식 있게 만들지 않는다.

### 신

- 지적이고 지휘관 같은 딱딱한 표현을 쓴다.
- 초반의 오만함·시험하는 태도와 후반의 취약함을 분명히 구분한다.
- MMO 문맥에서는 **길마/밴/레이드**처럼 실제 사용되는 짧은 게임 용어를 쓴다.

### 히메카미

- 성실하고 공손한 우등생 말투다. 죄책감과 불안을 과장 없이 드러낸다.
- 미우를 부를 때 `ミウ先生`은 **미우 선생님**으로 고정한다.

### 요미가에리 통신 / 튜토리얼

- 과장된 훈계조와 방송조를 유지한다.
- 지시는 `~하라`, `~하도록`, `명심하라` 계열을 우선하되 같은 어미를 기계적으로 반복하지 않는다.

### 시스템 메시지

- 간결한 해라체 또는 완료형으로 쓴다.
- 대표 완료형은 **획득했다**, **습득했다**, **봉인이 풀렸다**이다.
- 수치, 층수, 아이템 수량과 효과 범위를 임의로 바꾸지 않는다.

## 5. 문장부호와 감정

- 일본어의 `……`, 감탄, 더듬음, 말 끊김은 감정 정보다. 모두 `...`로 평준화하지 않는다.
- 원문에 없는 감탄사·욕설·성적 뉘앙스를 새로 만들지 않는다.
- 선택지는 마침표 없이 짧게 쓴다. 서술문은 화면에서 자연스러운 경우에만 종결 부호를 쓴다.
- 화자 이름이 명시되지 않은 문장은 앞뒤 문맥과 `bscr_file_contexts.json`의 장면 정보를 함께 보고 판단한다.

## 6. BSCR 불변조건

각 번역 단위마다 다음을 모두 지킨다.

1. **토큰 보존**: 입력의 `protected_tokens`를 같은 순서와 같은 횟수로 그대로 둔다. `$0`, `$1`, `$2`, `$3`, `$5` 및 패킷이 지정한 모든 토큰을 번역·삭제·추가하지 않는다.
2. **개행 보존**: 실제 LF(`\n`) 개수와 순서를 유지한다. 리터럴 두 글자 `\\n`으로 바꾸지 않는다. 줄을 합치거나 늘리지 않는다.
3. **바이트 상한**: `len(ko.encode("utf-8")) <= max_utf8_bytes`를 반드시 만족한다. 글자 수가 아니라 UTF-8 바이트 수다.
4. **슬롯 구조**: NUL(`\u0000`)을 넣지 않는다. 번역은 기존 NUL 종료 슬롯 안에 기록되고 남는 바이트만 0으로 채운다.
5. **기계 정보 보존**: 숫자, 연산 범위, 층수, 아이템 수량, 스킬·상태 효과의 의미를 바꾸지 않는다.
6. **식별자 안정성**: `translation_id`, UID, 파일, 세그먼트 인덱스, 오프셋, 일본어 원문을 수정하지 않는다.

바이트가 넘치면 의미와 말투를 유지한 채 한국어를 압축한다. 토큰 삭제, 개행 삭제, 핵심 정보 생략으로 상한을 맞추지 않는다.

## 7. 보존 대상과 금지된 판정법

다음 정규식에 정확히 일치하는 개발·배치 표식은 번역하지 않고 `preserve_pending`으로 둔다.

```regex
^TEST:.*パーティアウト\n?$
^.*lv[0-9]+用\n?$
^GO_OBJ配置\n?$
```

- 위 세 규칙은 **정확히 일치하는 문자열에만** 적용한다. 부분 일치나 비슷한 문구로 범위를 넓히지 않는다.
- 표시 소비자가 확인된 문자열은 영어판에도 일본어로 남아 있다는 이유로 보존하지 않는다.
- 내부 전용 또는 미참조 문자열은 소비자 증거가 추가될 때까지 번역 패킷에서 제외한다.

## 8. 초벌 및 통합 검수 기준

- 초벌: 일본어 의미 보존, 화자 문체, 고정 용어, 토큰·개행·바이트 상한을 단위별로 확인한다.
- 통합 검수: 같은 인물의 장면 진행에 따른 말투 변화, 호칭, 반복 용어, 선택지/후속 대사의 연결, 성적 표현의 누락, 숫자·효과 오류를 전체 묶음에서 한 번에 확인한다.
- 최종 지도에는 일본어 잔여 탐지 결과, 보호 토큰 비교, 개행 비교, UTF-8 바이트 검사를 모두 포함한다.
