# Criminal Girls Invite Only 한국어화 스타일 가이드 (초벌용)

## 작업 순서

1. 일본어 원문을 기준으로 전체 초벌 번역을 완성한다.
2. 공식 영어판은 의미·기능 확인용 보조 자료로만 쓴다.
3. 전체 초벌이 끝난 뒤에만 한 차례 통합 검수를 수행한다.
4. lookup key, 포맷 제어값, `dummy`, `予備`, `バッファ`, 순수 숫자는 번역하지 않는다.

## 문체

- 시스템 안내: 해요체보다 간결한 서술형/명령형을 우선한다. 예: `선택하세요`, `회복한다`.
- 전투 로그: 주어 뒤에 바로 이어 붙는 조사형 조각을 보존한다.
- 캐릭터 대사: 각 인물의 반말·사투리·말버릇과 감탄 부호 강도를 유지한다.
- 줄바꿈, `%`류 서식, 전각 공백, 선행·후행 조각은 기능을 확인한 뒤 보존한다.
- 일본어 기계 용어가 영어판에서 바뀌었더라도 일본어 슬롯의 화면 표기와 일관되는 쪽을 우선한다.

## 길이 원칙

- 메뉴명과 전투 명령은 원문과 비슷하거나 더 짧게 쓴다.
- 12px/14px 고정 셀 글꼴을 전제로 한 줄 폭을 짧게 유지한다.
- 이미지 UI는 화면별 목업 검수 후 실제 팔레트/IMY에 반영한다.

## 미확정

- `クリミナル`, `囚監フロア`, `誘惑`, 처벌 미니게임별 명칭은 전체 문맥을 모은 뒤 통합 검수에서 확정한다.
- 영어판의 `Maintenance`, `CM`, `Infirmary`, `Temptation`은 직역하지 않고 일본어 원문 설정을 우선한다.
